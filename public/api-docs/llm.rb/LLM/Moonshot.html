Overview

The Moonshot class implements a provider for Moonshot AI through its OpenAI-compatible Kimi API.

Examples:

#!/usr/bin/env ruby
require "llm"

llm = LLM.moonshot(key: ENV["KEY"])
ctx = LLM::Context.new(llm)
ctx.talk "Hello"
